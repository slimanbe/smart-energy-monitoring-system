# Smart Energy Monitoring System

## Description
This project presents a real-time smart energy monitoring system based on WT32-ETH01, PZEM-004T, MQTT communication, and a Python dashboard.

## Features
- Real-time voltage/current monitoring
- HTTP communication
- Ethernet/Wi-Fi connectivity
- Python dashboard visualization
- Data acquisition using PZEM-004T

## Technologies Used
- Python
- C++
- HTTP
- WT32-ETH01
- PZEM-004T

## Repository Structure
- Python_Dashboard/: Python monitoring application
- ESP32_Firmware/: WT32 firmware source code
